Map the shapes onto the wall

This is the projector screen. Drag the corners and the wall follows.

Drag each corner (A top-left, B top-right, C bottom-right, D bottom-left) onto the matching corner on the wall, or drag inside a shape to move it. Hold Shift while dragging for fine control. Click a corner, then use the arrow keys to nudge it one projector pixel (Shift: 10). Width ÷ height is the shape's real proportions, which phones draw on; Match the wall takes them from the corners. Changing them clears the drawing.

Print the sheet template, have visitors draw inside the boxes, then place the finished sheet under the camera. Each box's drawing goes to the same box on the wall, in one random colour per sheet. Uses your mapped shapes.

Waiting for a sheet.

Building outline

For paper drawing: print the template, draw on it with a dark marker. Its light-blue lines are too faint to be captured, so only your drawing is projected.

Paper

Detection looks for a white sheet on a darker surface. Press Lock once the outline fits, so a hand at the edge can't move it.

Ink detection

Ink is captured once it has stayed put for the hold time with nothing moving close to it, so the pen and hand aren't picked up.

Particles

Keys: Space or C clears (works in this window and the output window). A USB button set to send Space works as a physical clear button. On the output window, M lines the picture up with the real wall: drag the corners onto it. With Draw on screen you can also draw right on the output window with the mouse.
